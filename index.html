ABOUT VULNSCANNER

Nmap Security Assessment Platform

VULNSCANNER is a local Flask-based security assessment dashboard built around Nmap. It provides a web interface for authorized network scanning and presents the results in a structured, easy-to-read format.

  • Host discovery and TCP/UDP scanning
  • Service and version detection
  • Optional OS detection and NSE script execution
  • Severity-based vulnerability findings and risk scoring
  • Scan history and scan-to-scan comparison
  • PDF report generation

Technology: Python, Flask, Nmap, XML parsing and ReportLab.

Security note: Only scan systems you own or have explicit permission to assess.
