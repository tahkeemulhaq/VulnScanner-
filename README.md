# VulnScanner — Nmap Security Assessment Platform

## Run

1. Install Nmap:
   macOS:
   brew install nmap

2. Create/activate your Python environment.

3. Install Python dependencies:
   pip3 install -r requirements.txt

4. Start:
   python3 app.py

5. Open:
   http://127.0.0.1:5001

## Project features

- Host discovery
- Quick, standard and full TCP scans
- UDP scanning
- Targeted custom-port scans
- Service/version detection
- OS detection
- NSE script selection
- Vulnerability/CVE parsing
- Risk score
- Scan history
- Scan comparison
- PDF reports
- Cybersecurity dashboard with live radar and Nmap console

Use the scanner only against systems and networks you are authorized to assess.
